(Requirements)

- JDK: Java 17 atau Java 21
- IDE: Apache NetBeans 17+ (disarankan)
- Build Tool: Maven

Cara Menjalankan Aplikasi
1. Clone repository ini.
2. Buka Apache NetBeans.
3. Pilih File lalu Open Project, lalu pilih folder proyek "KalkulatorKalori".
4. Klik kanan nama proyek di panel sebelah kiri, pilih "Clean and Build".
5. Buka file "src/main/java/com/mycompany/kalkulatorkalori/Main.java".
6. Klik kanan file "Main.java" pilih "Run File".
